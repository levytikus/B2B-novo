# Business 2 Brothers

Site da Business 2 Brothers: sites, identidade visual e presença digital para pequenos e médios negócios.

## Onde mexer

- **Textos:** `index.html` (cada seção está marcada com um comentário `===== Nome =====`)
- **Cores e fontes:** variáveis no topo do `style.css`
- **Número do WhatsApp:** `WHATSAPP_NUMBER` na primeira linha do `script.js`
- **Mensagem de cada botão de WhatsApp:** atributo `data-msg` no `index.html`

## Imagens

As imagens ficam em `assets/`. Para trocar uma, substitua o arquivo mantendo o mesmo nome:

| Arquivo | O que é |
|---|---|
| `hero.webp` | Foto do Levy e do Nathan no topo |
| `sobre.webp` | Foto no quadro de post-its |
| `cta.webp` | Notebook do bloco de contato |
| `proj-*.webp` | Print do site de cada cliente |
| `logo-*.webp` | Logos dos clientes nos depoimentos |

## Publicação

Publicado com GitHub Pages a partir da branch `main`, pasta raiz.
